# Ezequiel Besser · páginas web

- `index.html`: página personal de clases particulares, publicada en https://ezebesserr.github.io/Ezequiel-Besser-repositorio-1/
- `muestras/`: webs de muestra con negocios inventados. Ferretería: https://ezebesserr.github.io/Ezequiel-Besser-repositorio-1/muestras/ferreteria/
- Muestras de los servicios: informe mensual de Presencia (`muestras/presencia/`) y catálogo con precios al día (`muestras/catalogo-vivo/`).
- `talleres/`: el taller «IA para tu comercio» y la guía para los participantes.
- `flyer/`: flyer para locales gastronómicos, para mandar por WhatsApp (`flyer.png`): https://ezebesserr.github.io/Ezequiel-Besser-repositorio-1/flyer/
- `CLAUDE.md`, `.claude/skills/` y `creador/`: **El Creador de Páginas Web**, la configuración para trabajar con Claude Code (instrucciones, skills, preferencias de diseño, precios).

Para usarlo, abrí una sesión de Claude Code con este repositorio y pedile, por ejemplo, «Armá la muestra para un restaurante» o «Buscá clientes en Caballito».
